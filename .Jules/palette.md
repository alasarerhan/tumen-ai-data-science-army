## 2026-04-21 - Improving Sidebar Accessibility with Radix Tooltips
**Learning:** Standard native `title` attributes on icon-only buttons provide poor UX and inconsistent accessibility. Using accessible Tooltip components combined with `sr-only` text labels ensures that collapsed navigation elements are both visually informative and screen-reader friendly.
**Action:** Always wrap icon-only links or buttons in a Tooltip component and include a visually hidden label for accessibility when designing collapsed or icon-centric interfaces.
